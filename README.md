# Cub3d



Cub3d is a simple 3D game built using the **MiniLibX** library, inspired by the classic **Wolfenstein 3D** game. This project is a part of the 42 school curriculum and aims to provide an introduction to the fundamentals of 3D graphics rendering and game development.

## About the Project

Cub3d is a project that demonstrates the basics of raycasting, which is a technique used in early 3D video games to simulate a 3D perspective in a 2D environment. This project will give you hands-on experience with rendering graphics, handling user input, and managing game states.

## Features

- Basic 3D rendering using raycasting
- Simple texture mapping
- Keyboard controls for navigation
- Basic collision detection

## Getting Started

### Prerequisites

Before you begin, ensure you have met the following requirements:

- **gcc** or another C compiler installed
- **Make** build tool
- **MiniLibX** library (included in the project or provided by 42)
- **X11** development libraries on Linux or **XQuartz** on macOS
